Setup guide

Getting it running

Everything on this page is for the person installing. Nothing here is needed to play — once it is in, it starts on its own.

Requirements · Playing alone · Running a server · Joining a server · Config · Commands · Updating · When something is wrong

Requirements

MinecraftJava Edition 26.2. Not Bedrock, not another version.
LoaderFabric Loader for 26.2.
LibraryFabric API 0.156.0+26.2. Not optional — the mod will not load without it.
Java25 or newer. java -version must say 25+, not 17 or 21. The vanilla launcher's bundled Java for 26.2 is fine.
The modherobrine-<version>.jar from the latest release.

Playing alone

  1. Run the Fabric installer. Pick 26.2, keep the default loader version, install. It creates a "fabric-loader-26.2" profile in the vanilla launcher.
  2. Open your mods folder (create it if it is not there):
    Windows%appdata%\.minecraft\mods
    macOS~/Library/Application Support/minecraft/mods
    Linux~/.minecraft/mods
  3. Put fabric-api-0.156.0+26.2.jar in it.
  4. Put herobrine-<version>.jar beside it.
  5. Launch the Fabric profile, not the vanilla one. Make a new world. Play normally.
Don't go looking. The first hour is meant to feel like nothing is installed. If you need to prove to yourself that it loaded, type /herobrine status — if the command exists, it did.

Running a server

For the machine hosting the game. Players joining it do something different — see Joining a server.

  1. Get the Fabric server launcher for 26.2. Java 25+ on the host.
  2. Run it once so it creates mods/, server.properties and eula.txt. Accept the EULA.
  3. Put both jars in mods/: Fabric API and Herobrine.
  4. Start it again. The log says wrote a default config to config/herobrine.json the first time.
The server and every client must run the same version of this mod. Not close — the same. A player on 2.82.4 joining a 2.82.5 server gets a confusing disconnect, not a clear message. When you update the server, hand every player the new pack.

Settings that matter

  • simulation-distance: he needs ticking chunks to do anything. The default 10 is ample; below 5 his sightings get unreliable.
  • view-distance only affects whether distant buildings are visible. 8 or more is fine.
  • No whitelist, permission plugin or extra port is needed.

With several people

  • Wrath is one number for the whole world. Six people reach the late phases far faster than one.
  • There is only ever one of him. If he is busy with somebody, everybody else gets a quiet night.
  • Buildings appear when the first player comes within 112 blocks, and are then permanent for everyone.
  • In the fight, two players raise his count by half; four double it. Dying alone rolls the fight back to the start of the act; dying with others standing changes nothing.
  • The ending is world-wide: when he dies, the rain stops and the people he turned are people again, for everyone.

Joining a server

A server cannot install a mod on your computer — Minecraft has never allowed it. You have to arrive already holding this mod, at the same version the server runs. The .mrpack on every release is that, in one file: it pins Fabric Loader, Fabric API and Herobrine by hash.

  1. Install Modrinth App or Prism Launcher.
  2. Download the .mrpack from the release your server runs (ask the host which).
  3. In the launcher: Add instance → Import (Prism) or Create profile → From file (Modrinth App) → pick the .mrpack. It fetches everything and makes a profile.
  4. Launch from that profile, not the vanilla launcher. Add the server as usual.
If the join is refused, nine times out of ten it is a version mismatch. Compare the .mrpack version with what the host installed.

Config

config/herobrine.json writes itself on first run. On a server the server's copy decides; a player's own copy does nothing to a multiplayer game. Everything is a switch; these are the ones people actually change:

KeyDefault
enabledtruethe whole mod
atmospheretruethe sky, fog and music changes as the story darkens
breakIntruehe breaks through walls, doors and cover; everything he breaks drops
realLightningtruehis bolts hurt and burn
blowsToKill100the length of the fight for one player
corpsestruethe dead stay where they fell and are looted like chests; a player's body holds their inventory
theTurningtruethe villager who does not sleep
hisKeep · keepBlueprinttrue · tutorial_castlethe castle, and which blueprint it is
houses · town · villageDecaytruethe places, and what happens to villages
weather · longerNights · endlessNighttruethe storm and the night in the later phases
quietDeathstrueno death messages for what he takes

Commands

All under /herobrine, all for testing. None are needed to play.

statuswrath, phase, where things stand — and proof the mod loaded
phase <name>jump the story to a phase (rumour, watcher, trespasser, mimic, hunter, siege)
boss [fresh]straight to the fight, in full diamond with his sword; resumes a bound fight unless fresh
resiteforget where unbuilt places were going to go; choose again near whoever is online
turnedput one of the turned in the nearest village

Updating

Every fix ships as a new release. Swap the jar in mods/; your world and your config carry over — every position, phase and flag is saved in the world itself. On a server, update the host and hand out the new .mrpack the same day.

When something is wrong

You seeIt means
The game crashes at launch mentioning fabric-apiFabric API is missing or the wrong version. It must be 0.156.0+26.2.
"Unsupported class file version" / Java errorsJava is older than 25. Install a current JDK, or let the launcher use its bundled one.
Refused when joining a serverYour mod version differs from the server's, or you launched the vanilla profile. Use the server's .mrpack profile.
Nothing happens for an hourCorrect. Keep playing.
/herobrine is unknownThe mod did not load. Check mods/ has both jars and read the log near startup.
The fight feels impossibleIt is meant to be very hard. Lower blowsToKill, or bring friends — and keep spare gear at home. Your body holds what you carried; go back for it.
