Setup guide

Getting it running

Four minutes, alone. A little longer for a server. Nothing on this page is needed to play — once it is installed, it starts on its own.

Before you start

Four things have to be true. If one of them is not, nothing else on this page will work.

Minecraft 26.2
Java Edition. Not Bedrock, not another version.
Fabric Loader
The mod loader. Get the installer →
Fabric API 0.156.0+26.2
A library every Fabric mod needs. Not optional. Download →
Java 25 or newer
The launcher's own Java for 26.2 is fine. If you run a server yourself, java -version must say 25 or higher.

Playing alone

  1. Install Fabric. Run the installer, choose 26.2, keep the suggested loader version, install. It adds a Fabric profile to your normal launcher.
  2. Open your mods folder. Create it if it is not there.
  3. Drop in two files. fabric-api-0.156.0+26.2.jar and herobrine-<version>.jar. Nothing else is needed.
  4. Launch the Fabric profile — not the vanilla one — and make a world.

Then play normally and don't go looking. The first hour is meant to feel like nothing is installed. If you want proof it loaded, type /herobrine status.

Running a server

This part is for the machine hosting the game. Everyone joining it does something different — see Joining a server.

  1. Get the Fabric server launcher for 26.2. fabricmc.net/use/server →
  2. Run it once so it writes mods/, server.properties and eula.txt. Accept the EULA.
  3. Put both jars in mods/ — Fabric API and Herobrine.
  4. Start it again. The log says wrote a default config to config/herobrine.json the first time.

Everyone must run the same mod version as the server. Not close — the same. A mismatch shows up as a confusing disconnect, not a clear message. When you update the server, hand out the new modpack the same day.

What changes with several people

  • Wrath is one number for the whole world, so six people reach the late phases far faster than one.
  • There is only ever one of him. While he is busy with somebody, everyone else gets a quiet night.
  • Buildings appear when the first player comes within 112 blocks, then stay for everyone.
  • In the fight, two players raise his count by half and four double it.
  • The ending is world-wide: the rain stops and the turned are cured for everyone at once.

Server settings worth a glance

  • simulation-distance — he needs ticking chunks. The default 10 is ample; below 5 his appearances get unreliable.
  • view-distance — only affects how far away buildings are visible. 8 or more is fine.
  • No whitelist, permission plugin or extra port is needed.

Joining a server

A server cannot install a mod on your computer — Minecraft has never allowed that. You have to arrive already holding it, at the same version the server runs. The .mrpack on every release does exactly that: it pins Fabric Loader, Fabric API and Herobrine by hash.

  1. Install a launcher that reads modpacks — Modrinth App or Prism Launcher.
  2. Download the .mrpack for the version your server runs. Ask the host which one.
  3. Import it. Prism: Add Instance → Import. Modrinth App: Create profile → From file.
  4. Launch from that profile and add the server as usual.

Settings

config/herobrine.json writes itself the first time the mod runs. On a server the server's copy is the one that decides. Everything is a switch; these are the ones people actually change.

enabledThe whole mod.
breakInHe breaks through walls, doors and cover. Everything he breaks drops, so nothing is lost but the wall.
realLightningHis lightning hurts and burns.
blowsToKillHow long the final fight is. 100 by default, for one player.
corpsesThe dead stay where they fell and are looted like chests. Your own body holds everything you carried.
atmosphereThe sky, fog and music changing as the story darkens.
theTurningThe villager who does not sleep.
houses · townThe places the story leads you to.
weather · endlessNightThe storm and the night that does not end, late on.
quietDeathsNo death messages for what he takes.

Commands

All for testing. None are needed to play, and using them will spoil things.

/herobrine statusWhere the story stands — and proof the mod loaded.
/herobrine phase <name>Jump to a phase: rumour, watcher, trespasser, mimic, hunter, siege.
/herobrine bossStraight to the fight, in full diamond with his sword. Add fresh to start it over.
/herobrine resiteChoose again where unbuilt places will go, near whoever is online.

Updating

Every fix ships as a new release. Swap the jar in mods/ — your world and your settings carry over, because every position, phase and flag is saved inside the world itself. On a server: update the host, then hand out the new modpack.

Something is wrong

It crashes at launch, mentioning fabric-api
Fabric API is missing or the wrong build. It must be 0.156.0+26.2.
"Unsupported class file version"
Java is older than 25. Use the launcher's bundled Java, or install a current JDK.
The server refuses the join
Your version differs from the server's, or you launched the vanilla profile instead of the modpack one.
/herobrine is an unknown command
The mod did not load. Check that mods/ holds both jars, and read the log near startup.
Nothing has happened for an hour
Correct. Keep playing.
The fight feels impossible
It is meant to be hard. Bring friends, keep spare gear at home, and remember your body holds what you carried — go back for it. Or lower blowsToKill.
